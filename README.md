# Jarvis

Desktop-Assistent für Windows (Neuronen-Kugel). Dieses Repo verteilt die Updates: Jede neue Version liegt unter **Releases**. Ein installiertes Jarvis (Setup) prüft beim Start und alle 4 Stunden, ob es hier eine neue Version gibt, und aktualisiert sich selbst.

Erstinstallation: unter Releases die neueste `Jarvis-Setup-x.y.z.exe` laden und starten.
